运行设置
点「循环出兵」后，本进程会自己一直循环：耐久不满的舰队先修复 → 修复完自动派出占领 → 战败回驻点后自动修复 → 修复完再派出，直到万吨货轮消失或今日奖励次数用完才停（不用你再点）。
派出顺序按品质优先级：先把万吨货轮占满（同一品质内优先进度高的），万吨没有或已达上限才退到中型，再退小型。
8:00~22:00 每个整点都会刷新一轮货轮，万吨也在其中（S4 的 19/21 点额外多刷 2 个万吨）。
历史日志
日志按天写到服务器的 logs/server-YYYY-MM-DD.log，保留 14 天。
进程意外停止时，先看这一天的最后几行；如果里面有 [fatal] 就是代码崩了（带堆栈）， 如果日志突然断掉、没有任何退出记录，说明是被强杀或内存不足（OOM），要去看 journalctl -u farmbot-console 和 dmesg。

更新只覆盖程序文件（js / web / 文档 / version.json）， 不会动 cfg/、game_src/、node_modules/、 cred.json、buf_login.bin、auth.json、guard.json，登录凭据和你的设置都会保留。

更新完成后进程会以退出码 75 退出，由 systemd（Restart=always）或 start.sh 自动拉起新版本。
